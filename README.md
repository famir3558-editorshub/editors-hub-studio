# Editors.Hub

A studio for video edits, as a Claude Code plugin: client projects, editing styles, drafts and timed review notes, a live view
of the work, a b-roll picker and render settings. It runs on your own computer, on Mac and Windows.

## Install

```bash
claude plugin marketplace add famir3558-editorshub/editors-hub-studio
```

```bash
claude plugin install editors-hub@editors-hub
```

Then start a new Claude session and say **"set up Editors.Hub"**. The first account on a computer is its owner. No GitHub account is needed.

It updates itself, keeping that computer's accounts, settings, videos, brand and keys.
